🍱 Cabinteria

Cabinteria is a smart food ordering system designed especially for college faculty members. Teachers can quickly order breakfast and lunch directly from their cabins without waiting in long queues.

This system helps save time, reduces crowd in canteens, and improves overall campus efficiency. Faculty members can easily browse the menu, select items, and place orders in a few clicks.

🔧 Technologies Used

  • Angular — Frontend UI
  • Spring Boot — Backend API
  • MySQL — Database
  • Bootstrap / CSS — Styling

🎯 Key Features

  • Quick food ordering for faculty
  • Separate breakfast & lunch menus
  • Real-time order tracking
  • Secure login system
  • Admin dashboard for canteen staff
